# javascript-calculator-precourse

## 📋 기능 목록

### 0. 실행

- [x] 입력 기능을 통해 사용자로부터 값을 입력받는다.
- [ ] 입력값을 커스텀 구분자 추출 기능으로 전달한다.
- [ ] 입력값과 커스텀 구분자를 숫자 추출 기능으로 전달한다.
- [ ] 추출한 숫자들을 숫자 합산 기능으로 전달한다.
- [ ] 출력 기능을 통해 합산한 수를 출력한다.

### 1. 입력 기능

    - [x] 사용자로부터 값을 입력받아 반환한다.
        - `Console.readLineAsync()`를 사용한다.

#### 2. 커스텀 구분자 추출

- [ ] 커스텀 구분자 기호(//\n)를 벗겨 구분자만 반환한다.
  - [ ] 구분자가 없을 경우 에러를 발생시킨다.
  - [ ] 구분자가 여러 문자(abc)인 경우 통째로 하나의 구분자로 취급한다.
- [ ] 커스텀 구분자가 없다면 null을 반환한다.

#### 3. 숫자 추출

    - [ ] 입력값에서 기본 구분자를 기준으로 숫자를 분리한다.
        - [ ] 커스텀 구분자가 존재할 경우 기본 구분자 대신 커스텀 구분자를 사용한다.
        - [ ] 구분자, 숫자를 제외한 문자를 포함할 경우 에러를 발생시킨다.
            - 예1: `1)2)3`
            - 예2: `//_\n1,2,3`
        - [ ] 연속해서 두 개의 구분자가 올 경우 에러를 발생시킨다.
    - [ ] 숫자 문자열을 BigInt 자료형으로 변환해 배열로 반환한다.
        - `Number.MIN_SAFE_INTEGER` ~ `Number.MAX_SAFE_INTEGE` 범위를 벗어나는 숫자도 정확히 계산하기 위함
    - 소수와 음수는 숫자로 처리하지 않는다
        - 커스텀 구분자와 소숫점, 음수 기호가 중복될 수 있음

### 4. 숫자 합산

    - [ ] 모든 숫자를 더한다.
    - [ ] 더할 숫자가 없을 경우 0을 반환한다.

### 5. 예외 처리

    - [ ] 에러 케이스일 경우 [ERROR]로 시작하는 메시지와 함께 `Error`를 발생시킨다.

### 6. 출력

    - [ ] 합산한 숫자를 `Console.print()`를 사용해 출력한다.
