# javascript-calculator-precourse

## 📋 기능 목록

### 0. 실행

- [x] 입력 기능을 통해 사용자로부터 값을 입력받는다.
- [x] 입력값을 커스텀 구분자 추출 기능으로 전달한다.
- [ ] 입력값과 커스텀 구분자를 숫자 추출 기능으로 전달한다.
- [ ] 추출한 숫자들을 숫자 합산 기능으로 전달한다.
- [ ] 출력 기능을 통해 합산한 수를 출력한다.

### 1. 입력 기능

    - [x] 사용자로부터 값을 입력받아 반환한다.
        - `Console.readLineAsync()`를 사용한다.
        - 구분자와 양수로 구성된 문자열이 입력으로 들어온다.

#### 2. 커스텀 구분자 추출

- [x] 커스텀 구분자 기호(//\n)를 벗겨 구분자만 반환한다.
  - [x] 구분자가 빈 문자열일 경우, 에러가 발생한다.
    - 빈 문자열과 공백은 구분한다.
- [x] 커스텀 구분자를 설정하지 않았다면 null을 반환한다.
- [ ] 커스텀 구분자가 온점('.')이면 에러가 발생한다.
  - 소숫점과 혼동될 수 있는 문제 예방
- 구분자가 여러 문자인 경우 통째로 하나의 구분자로 취급한다.
  - 예: `//--\n1--2--3` -> `--`

#### 3. 숫자 추출

    - [ ] 입력값에서 구분자를 기준으로 숫자를 분리한다.
        - [ ] 구분자, 숫자를 제외한 문자를 포함할 경우 에러를 발생시킨다.
            - 예1: `1)2)3`
            - 예2: `//_\n1,2,3`
        - [ ] 연속해서 두 개의 구분자가 올 경우 에러를 발생시킨다.
    - [ ] 숫자 문자열을 Number 자료형으로 변환해 배열로 반환한다.
    - [ ] `Number.MAX_SAFE_INTEGER`를 초과하는 숫자가 있을 경우 에러가 발생한다.

### 4. 숫자 합산

    - [ ] 모든 숫자를 더한다.
    - [ ] 더할 숫자가 없을 경우 0을 반환한다.

### 5. 예외 처리

    - [ ] 에러 케이스일 경우 [ERROR]로 시작하는 메시지와 함께 `Error`를 발생시킨다.

### 6. 출력

    - [ ] 합산한 숫자를 `Console.print()`를 사용해 출력한다.
